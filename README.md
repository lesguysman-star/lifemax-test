# LifeMax — version de test

Ce dépôt contient seulement le **site web de test** de LifeMax, construit automatiquement.
Il n'y a pas de code source ici.

Adresse du site : https://lesguysman-star.github.io/lifemax-test/

Pour l'installer sur un téléphone :

- **iPhone** : ouvre l'adresse dans Safari, bouton Partager, puis « Sur l'écran d'accueil » ;
- **Android** : ouvre l'adresse dans Chrome, menu (3 points), puis « Installer l'application ».

C'est une version de test : les données restent dans le navigateur du téléphone, il n'y a pas
de compte ni de sauvegarde en ligne.
